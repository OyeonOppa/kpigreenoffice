# ส่งต่อขยะ (#/pass-trash)

เกมไพ่โกหก-จับโกหก เล่นกับบอท 3–6 คน — ส่งไพ่ขยะคว่ำให้เพื่อน พร้อมบอกว่าทิ้งถังไหน (จริงหรือโกหกก็ได้)
ทายถูก → คนส่งเก็บไพ่ · ทายผิด → คนรับเก็บไพ่ · ใครมีขยะถังเดียวกันครบเกณฑ์ แพ้

| ไฟล์ | หน้าที่ |
| --- | --- |
| `cards.ts` | ไพ่ขยะ 40 ใบ (ชื่อ · ถัง · เหตุผลตอนเฉลย) ใช้รูปไอเท็มของเว็บที่มีอยู่ ถ้าไม่มีรูปใช้ emoji |
| `engine.ts` | ตรรกะเกมล้วน (รับ State คืน State ใหม่) + บอท · ไม่แตะ React จึงต่อกับห้องออนไลน์ได้ภายหลัง |
| `../pages/PassTrashPage.tsx` | หน้าจอ |
| `../../scripts/sim-pass-trash.mjs` | ให้บอทเล่นกันเอง + ตรวจกติกา (`node scripts/sim-pass-trash.mjs`) |

## เกณฑ์แพ้

`defaultLimit()` — 3–4 คน = ถังเดียวกันครบ 5 ใบ · 5–6 คน = ครบ 4 ใบ
จากการจำลอง (4,000 เกม/แบบ) ที่นั่งไหนก็แพ้พอๆ กัน และเกมจบได้เสมอ แต่เล่น 6 คนเกมมักจบเพราะไพ่ในมือหมด
(ตัดสินที่ผู้มีขยะถังเดียวกันมากที่สุด) มากกว่าเพราะครบเกณฑ์

## บอท

บอทไม่เห็นไพ่ที่คว่ำ — ประเมินจากไพ่ที่ยังไม่โผล่ (นับไพ่) แล้วเทียบความเสี่ยงของการเก็บไพ่เพิ่ม
แต่ละตัวมีนิสัยต่างกัน (`lie` โอกาสโกหก · `sus` ความระแวง) บอทเป็นแค่ตัวฝึกเล่น ไม่ได้เก่งเท่าคนจริง

## ที่ยังไม่ได้ทำ

- เล่นกับเพื่อนออนไลน์ (ต้องซ่อนไพ่ในมือที่ฝั่งเซิร์ฟเวอร์ — engine แยกไว้ให้ต่อได้)
- ยังไม่เคยเล่นทดสอบกับคนจริง
