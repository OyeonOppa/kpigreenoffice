# แคมเปญป่า 3R

ทุกคนมีต้นไม้ของตัวเองคนละต้น บันทึกกิจกรรม 3R แล้วได้แต้ม แต้มสะสมทำให้ต้นโตขึ้น
ต้นของคนในสำนักเดียวกันไปยืนรวมเป็นสวน

| หน้า | ใคร | ทำอะไร |
| --- | --- | --- |
| `#/forest` | ทุกคน | ปลูกต้นของตัวเอง → บันทึกกิจกรรมรายวัน → ดูต้นตัวเอง/สวนของสำนัก |
| `#/forest/staff` | สตาฟ | ค้นหาคน แล้วกดให้แต้มกิจกรรมพิเศษ (ไม่ได้ลิงก์จากที่ไหน) |
| `#/tree-lab` | คนทำเว็บ | ห้องทดลองปรับหน้าตาต้นไม้ (ไม่ได้ลิงก์จากที่ไหน) |

## แต้ม

แต้มมี 2 ทาง — **บันทึกเอง** กับ **สตาฟกดให้**

```
บันทึกเอง   ข้อละ 6–15 แต้ม · ข้อละ 1 ครั้งต่อวัน · รวมไม่เกิน 40 แต้ม/วัน
สตาฟกดให้   1–200 แต้ม · ไม่ติดเพดานรายวัน · ต้องมีเหตุผลกำกับเสมอ
```

เพดานรายวันมีไว้เพราะถ้าไม่มี คนกดครบทุกข้อในวันเดียวได้ 131 แต้ม = ต้นโตเต็มใน 5 วัน แล้วแคมเปญจบ
เพดาน 40 ทำให้ต้องกลับมาทำต่อเนื่องอย่างน้อย 15 วัน ซึ่งเป็นพฤติกรรมที่แคมเปญต้องการจริงๆ

ชนเพดานกลางคันจะได้แต้มเท่าที่เหลือ ไม่ใช่ถูกปฏิเสธ — คนที่ทำจริงแล้วไม่ควรได้ศูนย์

## การเติบโต

```
growth = แต้มสะสม / 600        (0 = เพิ่งปลูก, 1 = โตเต็มที่)
```

`growth` ส่งตรงเข้า `buildTree()` แล้วออกมาเป็นต้นที่สูงขึ้น แตกกิ่งมากขึ้น ใบหนาขึ้นอย่างต่อเนื่อง
ระยะทั้ง 7 (`STAGES`) เป็นแค่ป้ายชื่อทับบนค่าต่อเนื่องนี้ ไม่ได้มีโมเดลแยกรายระยะ

ชื่อระยะอิงขนาดต้นล้วนๆ ไม่มี "ออกดอก/ออกผล" เพราะ `treeGeometry` ยังสร้างแต่กิ่งกับใบ
และไม่เริ่มที่ "เมล็ด" เพราะ growth 0 วาดออกมาเป็นต้นเล็กที่มีใบแล้ว — ป้ายต้องตรงกับสิ่งที่เห็นบนจอ

## โครงไฟล์

```
forest/
  config.ts             FULL_POINTS / DAILY_CAP / GARDEN_MAX / STAGES  ← ปรับกติกาที่นี่
  types.ts              รูปร่างข้อมูลที่หน้าจอใช้
  backend.ts            interface กลาง — หน้าจอคุยกับหลังบ้านผ่านตัวนี้ตัวเดียว
  mockForestBackend.ts  หลังบ้านจำลอง (localStorage + BroadcastChannel)
  index.ts              จุดสลับ adapter   ← เปลี่ยนไปใช้ของจริงที่บรรทัดเดียวนี้
  hooks.ts              useForestAuth / useForest

content.ts              FOREST (รายการกิจกรรม + แต้ม + ข้อความ)
components/forest/      ForestScene (ฉาก+กล้อง+แสง), Tree3D, GrowingTree, MyTreeMarker, treeGeometry
pages/                  ForestPage, ForestStaffPage
```

## กฎของ 3D ที่ห้ามฝ่าฝืน

ได้มาจากการวัดจริงตอนทำ `#/tree-lab` ถ้าฝ่าฝืนคือจอขาวหรือเครื่องค้าง

1. **Canvas เดียวต่อหน้า** — สลับมุมมองด้วยการเปลี่ยนเนื้อหาข้างใน ห้าม unmount Canvas
   (เบราว์เซอร์จำกัดจำนวน WebGL context ต่อหน้า พอเกินจะ Context Lost)
2. **สวนใช้ LOD `low` เสมอ** ต้นเดี่ยวถึงจะใช้ `high` ได้
3. **สวนวาดไม่เกิน `GARDEN_MAX` (60) ต้น** — 48 ต้นที่ LOD low วัดได้ ~265,000 สามเหลี่ยม
   ถ้าปล่อยครบ 250 คนจะเป็นล้านกว่า มือถือไม่ไหว คนที่เกินโควตาแสดงเป็น "และอีก N คน"
4. **ห้ามไล่ค่า growth ทีละเฟรม** — `buildTree` แตกกิ่งใหม่ทั้งต้นแล้ว merge geometry
   ตอนโตขึ้นให้สลับทรงทันทีแล้วเด้ง scale กลับเข้าที่แทน (`GrowingTree`)
5. **สร้างทรงใหม่เฉพาะต้นที่แต้มเปลี่ยน** — snapshot เป็นก้อนใหม่ทุกครั้งที่มีใครได้แต้ม
   ถ้าสร้างใหม่ทั้งสวนตามไปด้วย จะกระตุกทุกครั้งที่มีคนกดปุ่ม

จำนวนคอลัมน์ของสวนปรับตามความกว้างจอ (มือถือ 4 จอคอม 8) และกล้องคำนวณระยะจากสัดส่วนจอจริง —
ถ้าใช้ค่าเดียวกันทุกจอ บนมือถือต้นริมสวนจะโดนตัดหายไปทั้งแถว

## หลังบ้าน: ยังเป็นโหมดจำลองเท่านั้น

`mockForestBackend` เก็บทุกอย่างใน `localStorage` ของเครื่องที่เปิด — เปิดคนละเครื่องคือคนละป่า
ใช้ดูหน้าตาและลองกติกาได้ครบ **แต่ใช้ในงานจริงไม่ได้**

ตอนทำของจริงให้เขียน adapter ใหม่ตาม `ForestBackend` แล้วสลับที่ `index.ts` จุดเดียว
หน้าจอไม่ต้องแก้ — แบบเดียวกับที่เกมแข่งสดสลับจาก mock ไป Cloudflare Worker มาแล้ว

สิ่งที่ adapter ของจริงต้องทำ (โหมดจำลองทำไม่ได้ทั้งหมด):

| เรื่อง | ต้องทำอะไร |
| --- | --- |
| ตัวตน | Google Sign-In + บังคับโดเมน `kpi.ac.th` แล้วให้เซิร์ฟเวอร์เป็นคนบอก uid จาก token — **ห้ามเชื่อ uid ที่หน้าจอส่งมา** ไม่งั้นใครก็ยิงขอแต้มใส่ uid คนอื่นได้ |
| ขอบเขตของวัน | ตรึงเป็นเขตเวลาไทยที่ฝั่งเซิร์ฟเวอร์ ตอนนี้ใช้นาฬิกาเครื่องผู้ใช้ — ตั้งนาฬิกาเองแล้วบันทึกซ้ำได้ |
| เพดานรายวัน | ต้องคิดที่เซิร์ฟเวอร์ ตอนนี้คิดในเครื่องผู้ใช้ |
| สิทธิ์สตาฟ | ตรวจที่เซิร์ฟเวอร์ว่าใครกดให้แต้มได้ — ซ่อน URL `#/forest/staff` ไม่ใช่การป้องกัน |
| สวน | ส่งเฉพาะ 60 ต้นที่ต้องวาดจริง + ตัวเลขสรุป ไม่ใช่รายชื่อทั้งหน่วยงาน (250 คน) ให้ทุกเครื่อง |

## สิ่งที่ยังไม่ได้ทำ

- **หลังบ้านจริง** — ข้อในตารางข้างบนทั้งหมด
- **รายการกิจกรรมจริง** — 13 ข้อใน `FOREST.activities` เป็นตัวตั้งต้น ต้องให้คณะทำงาน Green Office เคาะ
  ข้อไหนที่หน่วยงานยังไม่มีจุดรองรับ (จุดรับขยะอันตราย จุดทำปุ๋ย จุดเติมน้ำยา) ต้องตัดออก
  ไม่งั้นคนกดบันทึกได้แต้มทั้งที่ทำจริงไม่ได้
- **ป่าทั้งหน่วยงาน** — ตอนนี้มีแค่สวนรายสำนัก มุมมองรวม 250 ต้นต้องใช้ LOD ที่ต่ำกว่านี้อีกชั้น
- **แก้โปรไฟล์ทีหลัง** — ปลูกแล้วเปลี่ยนชื่อ/ลุค/สำนักเองไม่ได้ (`saveProfile` รองรับแล้ว ขาดแค่หน้าจอ)
- **แต้มจากเกมแยกขยะแข่งสด** — ยังไม่ได้ต่อเข้าด้วยกัน
