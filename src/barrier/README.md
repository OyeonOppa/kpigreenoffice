# ฝ่าด่านลดคาร์บอน (#/barrier)

เกมไพ่สองฝ่าย **ผลักดัน** vs **ต่อต้าน** — เล่นกับบอท เลือกเล่นได้ทั้งสองฝั่ง
ฝ่ายผลักดันวางมาตรการลดคาร์บอน ถ้ารอดจากด่านจะได้แต้ม **ทุกตา** ไปจนจบเกม · ถึงเป้าตามการ์ดสัญญา (125 / 175 / 225) ชนะ
ได้แรงบันดาลใจด้านโครงสร้างจากเกม *Bangkok's Big Brother: เราจะทำตามสัญญา* ของ iLaw (ควรให้เครดิตและติดต่อ iLaw ก่อนเผยแพร่เป็นทางการ)

| ไฟล์ | หน้าที่ |
| --- | --- |
| `cards.ts` | ข้อมูลการ์ดทั้งหมด (มาตรการ 17 · ด่าน 16 · ข่าวลือ/ล้างกระดาน/ตัดงบ/ข้อมูลกระจัดกระจาย · ไอเท็ม 3+3 · กุญแจ) |
| `engine.ts` | ตรรกะเกมล้วน (รับ State คืน State ใหม่) + บอททั้งสองฝั่ง · ไม่แตะ React จึงต่อกับห้องออนไลน์ได้ภายหลัง |

| `../../scripts/sim-barrier.mjs` | ให้บอทเล่นกันเอง + ตรวจกติกา (`node scripts/sim-barrier.mjs` ต้องใช้ Node 22.18+) |

## แกนความรู้ของเกม

ด่านแต่ละแบบแก้ด้วยกุญแจที่ **ตรงกัน**: 💸 แพง→💰 คิดความคุ้ม · ❓ ไม่รู้วิธี→📚 ความรู้ · 🙄 เคยชิน→👥 ชวนกัน ·
🌀 ยุ่งยาก→🛠️ ทำให้ง่าย · 👀 มองไม่เห็นผล→📏 วัดผลให้เห็น · ⭐ แก้ได้ทุกด่านแต่มีใบเดียว
เนื้อหาบนการ์ดเป็นหลักการทั่วไปที่ไม่ผูกกับนโยบายหรือราคาของปีใดปีหนึ่ง

## ผลจำลองบอท vs บอท (6,000 เกม, ไอเท็มเริ่มต้น 🏫 vs 📺)

คะแนนกลาง ~163 · เฉลี่ย ~23 ตา · ฝ่ายผลักดันชนะ ~69% / 45% / 24% เมื่อเป้า 125 / 175 / 225 · ไม่มีเกมค้าง
สูตรปัจจุบัน: มาตรการ 17 · กุญแจ 8 (ลดจาก 11 เพราะผู้เล่นจริงมือเต็มกุญแจ) · กองผลักดัน 31 ใบเท่าเดิม

## ที่ยังไม่ได้ทำ / ข้อควรรู้

- **ยังไม่เคยเล่นทดสอบกับคนจริง** บอทเล่นง่ายกว่าคนมาก ตัวเลขเป็นแนวทางเท่านั้น
- การ์ด ✂️ ตัดงบ กับ 🗂️ ข้อมูลกระจัดกระจาย แทบไม่มีผลต่อคะแนนในการจำลอง (ถอดออกแล้วคะแนนไม่เปลี่ยน)
- ด่านคว่ำและการ์ด 📉 เปลี่ยนคนทำ เป็นสองกลไกที่เปลี่ยนเกมได้มากที่สุด ถ้าฝั่งใดได้เปรียบเกิน ปรับที่สองจุดนี้ก่อน
- เล่นกับเพื่อนออนไลน์ยังไม่ได้ทำ (ต้องซ่อนไพ่ในมือที่ฝั่งเซิร์ฟเวอร์)
