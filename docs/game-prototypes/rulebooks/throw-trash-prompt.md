# Prompt: สร้างเกมการ์ด "โยนขยะ!" (เล่นออนไลน์กับบอท)

คัดลอกทั้งหมดด้านล่างนี้ไปวางในโปรเจกต์ใหม่ได้เลย

---

ช่วยสร้างเกมการ์ดปาร์ตี้ภาษาไทยชื่อ **"โยนขยะ!"** เป็นหน้าเว็บเล่นได้จริง (เล่นคนเดียวกับบอท 1–5 ตัว) เกี่ยวกับการแยกขยะ 4 สี เนื้อหาสำหรับสอนโรงเรียน/ชุมชน UI ต้องน่ารัก สดใส ใช้อีโมจิเป็นภาพการ์ด

## Tech
- Next.js (App Router) + React + TypeScript + Tailwind ถ้าโปรเจกต์ใช้อยู่แล้ว ให้ใช้ตาม convention เดิม
- หน้าเกมเป็น client component ที่ `/throw-trash`
- แยกไฟล์: `cards.ts` (ข้อมูลการ์ด + สร้างกอง), `engine.ts` (ตรรกะเกมล้วน ไม่ผูก React), `page.tsx` (UI)
- ฟอนต์ Noto Sans Thai, ปุ่มและแท็กทรงแคปซูล, การ์ดมุมโค้ง, สีหลักเขียว #22C55E

## แนวคิดเกม
ผู้เล่นแต่ละคนมี "บ้าน" (ที่เก็บขยะ) กับ "โซนบัฟ" (การ์ดบัฟที่ลงแล้ว)
**ใบไม้สุทธิ = ผลรวมใบไม้บนการ์ดบัฟ − จำนวนขยะที่ค้างในบ้าน**
ใครมีใบไม้สุทธิ ≥ 10 ตอนจบตาของตัวเองก่อน ชนะ (เก็บเป็นค่าคงที่ `WIN = 10`)
เล่นได้ 2–6 คน (คน 1 + บอท 1–5)

## กองการ์ด (110 ใบ)
**ขยะ 40 ใบ** (แต่ละใบเก็บ `bin` ที่ถูกต้อง และแสดงเฉลยตัวเล็กกลับหัวที่มุมขวาล่างของการ์ด)
- เขียว (10): เปลือกกล้วย, เศษข้าว, เปลือกส้ม, กระดูกไก่, เศษผัก, ก้างปลา, ใบไม้แห้ง, กากกาแฟ, เปลือกไข่, เปลือกแตงโม
- เหลือง (11): ขวดน้ำพลาสติกใส, กระป๋องน้ำอัดลม, กล่องกระดาษ, หนังสือพิมพ์, ขวดแก้ว, กระดาษ A4, ขวดน้ำมันพืช, กระป๋องนมเปล่า, หนังสือเก่า, ขวดน้ำอัดลม PET, กล่องนมล้างสะอาด
- น้ำเงิน (10): ถุงขนมเปื้อน, แก้วกาแฟเปื้อน, ทิชชู่ใช้แล้ว, โฟมใส่อาหาร, ถุงพลาสติกเปื้อน, หลอดดูด, ซองบะหมี่, แปรงสีฟันเก่า, ถ้วยโยเกิร์ตเปื้อน, ฟองน้ำล้างจาน
- แดง (9): ถ่านไฟฉาย, หลอดไฟ, กระป๋องสเปรย์, ขวดยาฆ่าแมลง, ยาหมดอายุ, แบตเตอรี่มือถือ, เทอร์โมมิเตอร์ปรอท, ตลับหมึกพิมพ์, กระป๋องสีทาบ้าน

**การ์ดถัง 20 ใบ** สีละ 5 ใบ

**การ์ดบัฟ 25 ใบ** (key, ชื่อ, ใบไม้, จำนวน, ผล)
- tree ปลูกต้นไม้ +1 ×6 — ไม่มีผลพิเศษ
- solar โซลาร์รูฟ +3 ×2 — ต้องทิ้งการ์ดอื่นในมือ 2 ใบ (ผู้เล่นเลือก)
- compost ทำปุ๋ยหมัก +1 ×3 — ขยะสีเขียวทุกใบในบ้านตัวเองถูกทิ้งทันทีโดยไม่ต้องใช้ถัง
- bank ธนาคารขยะ +2 ×3 — ต้องทิ้งขยะสีเหลืองจากมือ 3 ใบ
- bag ใช้ถุงผ้า +1 ×3 — กันการ์ด "แจกถุงพลาสติก" ถาวร
- light ปิดไฟก่อนกลับ +1 ×3 — จั่วเพิ่ม 1 ใบ
- repair ซ่อมแทนซื้อใหม่ +2 ×2 — นำขยะ 1 ใบในบ้านกลับขึ้นมือ
- friend ชวนเพื่อนแยกขยะ +1 ×3 — เลือกผู้เล่น 1 คน คุณและเขาจั่วคนละ 1 ใบ

**การ์ดแกล้ง 15 ใบ**
- burn เผาขยะ! ×2 — ขยะในบ้านตัวเองหมด แต่ตัวเองกับคนซ้าย-ขวาทิ้งการ์ดบัฟมูลค่าต่ำสุดคนละ 1 ใบ (เล่นได้เมื่อบ้านมีขยะ) เป็นบทเรียนว่าการเผาทำให้ทุกคนเดือดร้อน
- bags แจกถุงพลาสติก ×2 — ทุกคนรับขยะน้ำเงินใหม่ 1 ใบลงบ้าน (คนมีถุงผ้าไม่รับ)
- lights เปิดไฟทิ้งไว้ ×3 — เลือก 1 คน ทิ้งบัฟมูลค่าต่ำสุด 1 ใบ
- wind ลมพัดขยะ ×3 — เลือกขยะ 1 ใบจากบ้านใครก็ได้ ย้ายไปบ้านคนอื่นที่เลือก
- gift ของแถมฟรี ×3 — ยัดขยะ 2 ใบจากมือให้ผู้เล่น 1 คน นับเป็นการโยนขยะ 1 ครั้ง
- smoke ควันจากการเผา ×2 — ทุกคนที่มีขยะในบ้านตั้งแต่ 3 ใบ ทิ้งการ์ดในมือ 1 ใบแบบสุ่ม

**การ์ดป้องกัน 10 ใบ** (เล่นนอกตาได้ ระบบถามผู้เล่นเองเมื่อถูกโจมตี)
- nobag ไม่รับถุงค่ะ ×4 — ยกเลิก "แจกถุงพลาสติก" หรือ "ของแถมฟรี" ที่ใส่ตัวเอง
- muni แจ้งเทศบาล ×3 — ขยะที่ถูกโยนใส่บ้านเรา ส่งกลับไปบ้านคนโยน
- lid ถังมีฝาปิด ×3 — ยกเลิก "ลมพัดขยะ" หรือ "ควันจากการเผา"

## กติกาการเล่น
- เริ่มเกม แจกคนละ 5 ใบ
- ต้นตา: ถ้ามีขยะแดงค้างในบ้าน ทิ้งบัฟมูลค่าต่ำสุด 1 ใบ แล้วจั่ว 1 ใบ
- ทุกตามี **2 สิทธิ์** แต่ละสิทธิ์เลือกทำอย่างใดอย่างหนึ่ง:
  1. **ลงการ์ดบัฟ** ไปไว้โซนบัฟ แล้วทำตามผล
  2. **แยกขยะ** เล่นการ์ดถัง 1 ใบ แล้วเลือกขยะ 1 ใบในบ้านตัวเอง ถ้าสีถูก ทิ้งทั้งคู่ลงกองทิ้ง
  3. **โยนขยะ** เล่นการ์ดขยะจากมือลงบ้านคนอื่น (ไม่เกิน 1 ครั้งต่อตา) ผู้ถูกโยนใช้ "แจ้งเทศบาล" ได้
  4. **เล่นการ์ดแกล้ง**
- **จับผิด!**: ถ้าเลือกขยะลงถังผิดสี ขยะยังค้างในบ้าน และเปิดช่วงจับผิด 3.5 วินาที ผู้เล่นคนไหนกด "✋ จับผิด!" ทันก่อน ได้การ์ดถังใบนั้นไปวางโซนบัฟ นับเป็น +1 ใบไม้ ถ้าไม่มีใครจับทัน การ์ดถังลงกองทิ้ง
- **รถเทศบาล 🚛**: หลังทุกการกระทำ ถ้าบ้านใครมีขยะ ≥ 5 ใบ เก็บให้ 2 ใบ (เก็บขยะแดงก่อน)
- จบตา: มือเกิน 7 ใบต้องทิ้งจนเหลือ 7 (ผู้เล่นเลือกเอง บอทเลือกการ์ดที่มีค่าน้อยสุด) แล้วเช็คว่าใบไม้สุทธิ ≥ WIN หรือไม่
- กองจั่วหมด สับกองทิ้งเป็นกองจั่วใหม่

## สถาปัตยกรรม engine
- `Game` class เก็บ state เดียว (mutable) ได้แก่ players, deck, discard, turn, actions, thrown, humanTurn, log, winner
- มี `UI` interface ที่ engine เรียกเมื่อต้องถามผู้เล่น (return Promise): `pickTarget`, `pickCards` (เลือก n ใบ มี label ต่อใบ ยกเลิกได้/ไม่ได้), `confirm` (ถามใช้การ์ดป้องกัน), `catchWindow`, `endCatch`, `render`, `toast`
- ฟังก์ชันหลัก `play(playerIndex, card)` ใช้ร่วมกันทั้งคนและบอท: ตรวจเงื่อนไข → ถามตัวเลือก (คนถาม UI / บอทเลือกเอง) → ทำผล → หักสิทธิ์ → เช็ครถเทศบาล ถ้าเงื่อนไขไม่ผ่านให้ toast บอกคนเล่น และไม่หักสิทธิ์
- ผู้โจมตีทุกแบบต้องผ่านฟังก์ชัน `react(victim, key)` ที่ถามคนว่าจะใช้การ์ดป้องกันไหม ส่วนบอทใช้ถ้ามี (โอกาส 90%)
- ช่วงจับผิด: ให้ผู้เล่นทุกคนยกเว้นคนที่แยกผิด แข่งกัน คนกดตามเวลา บอทมีโอกาสจับ 45–60% ภายใน 0.9–3.1 วินาที ผู้ชนะคือคนแรกที่ตอบ
- วงเกม `run()` เป็น async loop: startTurn → (คน: รอ promise จนกด "จบตา" / บอท: botAct สูงสุด 2 ครั้ง คั่นด้วย delay ~1 วิ) → finishTurn → ตา next
- ผู้เล่นคนมี index 0 เสมอ เพิ่ม flag `busy` กันกดซ้อนระหว่างรอ prompt และมี `destroy()` ยกเลิกวงเกมตอน unmount
- **บอท AI**: สร้างรายการการกระทำที่ทำได้พร้อมน้ำหนัก สุ่มบวกเล็กน้อย แล้วลองตามลำดับจนสำเร็จ — แยกขยะถูก (100) > ลงบัฟ (50 + ค่าใบไม้×10) > โยนขยะ (55) > การ์ดแกล้ง (burn 75 เมื่อบ้านมีขยะ ≥3 ฯลฯ) บอทแยกผิดถังโดยตั้งใจ 12% เพื่อให้คนมีโอกาสจับผิด เป้าหมายของการโจมตีคือคนที่ใบไม้สุทธิสูงสุด

## UI
- หน้าเริ่ม: สรุปกติกาสั้นๆ, ตารางถัง 4 สี, เลือกจำนวนบอท 1–5, ปุ่มเริ่มเล่น
- หน้าเล่น: แถบสถานะ (ตาของใคร, สิทธิ์ที่เหลือ ●●, กองจั่ว, เป้าหมาย) → การ์ดผู้เล่นคู่แข่ง (อวตาร, จำนวนการ์ดในมือ, ใบไม้สุทธิตัวใหญ่, ชิปบัฟ, ชิปขยะในบ้านที่ขอบสีตามถัง, เตือน "ใกล้ครบ 5!") → ล็อกเหตุการณ์ 5 บรรทัดล่าสุด (ล่าสุดตัวหนา) → แผงผู้เล่นเรา → มือการ์ดเลื่อนแนวนอน + ปุ่ม "จบตา" (กระพริบเมื่อหมดสิทธิ์) + คำอธิบายถัง
- การ์ดขนาด ~108×150px มีแท็กประเภท (ขยะ/ถัง/บัฟ/แกล้ง/ป้องกัน) แต่ละประเภทคนละสี การ์ดถังใช้รูปทรงตัวใหญ่ การ์ดขยะมีเฉลยกลับหัวมุมขวาล่าง
- Modal: เลือกเป้าหมาย (ปุ่มอวตาร + ใบไม้ + จำนวนขยะ), เลือกการ์ด (กดเลือกจนครบ แล้วยืนยัน), ถามใช้การ์ดป้องกัน (ใช้เลย/ไม่ใช้), ปุ่มใหญ่ "✋ จับผิด!" ลอยด้านล่างพร้อมอนิเมชัน pulse, toast แจ้งเมื่อเล่นการ์ดไม่ได้
- จบเกม: modal แสดงผู้ชนะ อันดับทุกคน จำนวนรอบ ปุ่มเล่นอีกครั้ง
- ต้องใช้ได้ทั้งมือถือและเดสก์ท็อป

## ข้อกำหนดเพิ่มเติม
- ข้อความทั้งหมดในเกมเป็นภาษาไทย
- ห้ามผูกตรรกะเกมกับ React เพื่อให้ต่อ realtime multiplayer (Supabase) ภายหลังได้ โดยเปลี่ยนแค่ฝั่ง `UI` และทำให้ state serialize ได้
- ทดสอบโดยเล่นจริงในเบราว์เซอร์ให้ครบ: โยนขยะ, แยกถูก/ผิด, จับผิด, ใช้การ์ดป้องกัน, ลมพัดขยะ, โซลาร์, ทิ้งการ์ดเมื่อมือเกิน 7, หน้าจบเกม แล้วรายงานสิ่งที่ยังไม่ได้ทดสอบ
