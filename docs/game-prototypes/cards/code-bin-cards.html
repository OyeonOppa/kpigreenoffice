รหัสลับถังขยะ 🔎

เกมให้คำใบ้เป็นทีม + แยกขยะ · 4–10 คน · อายุ 10+ · 20 นาที

เป้าหมาย

สองทีม (ทีมส้ม ★ กับ ทีมม่วง ✚) แข่งกันเก็บ "ขยะของทีมตัวเอง" ให้ครบก่อน — ต้อง เดาให้ถูกว่าการ์ดไหนเป็นของทีม และ บอกถังที่ขยะชิ้นนั้นต้องทิ้งให้ถูก

เตรียมเกม

  1. แบ่งสองทีม แต่ละทีมเลือก หัวหน้าทีม 1 คน (ผู้ให้คำใบ้) ที่เหลือเป็นผู้ทาย
  2. สับการ์ดขยะ 60 ใบ วางหงาย 4 ช่อง × 5 แถว = 20 ใบ กลางโต๊ะ
  3. หัวหน้าสองทีมจั่ว การ์ดแผนที่ลับ 1 ใบ ดูแล้วตั้งไว้ไม่ให้ทีมเห็น (ทั้งสองคนใช้ใบเดียวกัน) บนการ์ดบอกว่าทีมไหนเริ่มก่อน และช่องไหนเป็นของใคร
  4. วาง การ์ดคลุม ข้างโต๊ะ ใช้ปิดการ์ดที่ทีมเก็บได้
ในแผนที่ลับ มี 20 ช่องจำนวน
ทีมที่เริ่มก่อน8
ทีมที่เริ่มทีหลัง7
กลาง ○ (ไม่ใช่ของใคร)4
🔥 ขยะเพลิง (ห้ามแตะ!)1

ตาของทีมหนึ่ง

  1. หัวหน้าให้คำใบ้ 1 คำ + ตัวเลข เช่น "ครัว 3" = มี 3 ใบของทีมเราที่เกี่ยวกับ "ครัว"
    • ต้องเป็นคำเดียว ห้ามเป็นชื่อสิ่งของบนกริดหรือบางส่วนของชื่อนั้น
    • ห้ามใช้คำเกี่ยวกับถัง: ถัง · สี · เขียว/เหลือง/น้ำเงิน/แดง · รีไซเคิล · อันตราย · เศษอาหาร · ขยะทั่วไป
    • ห้ามบอกใบ้ด้วยท่าทาง เสียง หรือสีหน้า
  2. ผู้ทายปรึกษากัน แล้วแตะการ์ด 1 ใบ ทายได้ไม่เกิน ตัวเลข + 1 ใบ และต้องทายอย่างน้อย 1 ใบ
  3. หัวหน้าบอกว่าใบนั้นเป็นของใคร (ดูจากแผนที่ลับ):
    • ของ ทีมตัวเอง → ไปข้อ 4
    • ของ อีกทีม → วางการ์ดคลุมสีทีมนั้นทับ (เป็นแต้มของเขา) จบตา
    • กลาง ○ → วางการ์ดคลุมกลาง จบตา
    • 🔥 ขยะเพลิง → ทีมนี้แพ้ทันที
  4. ด่านถัง: ผู้ทายต้องพูดว่าขยะชิ้นนั้นทิ้ง ถังไหน แล้วให้หัวหน้าทีมตรงข้ามเปิด หน้าเฉลย (ท้ายเล่ม) ตรวจ
    • ตอบถังถูก → วางการ์ดคลุมสีทีมตัวเองทับ ทายต่อได้ถ้ายังไม่ครบจำนวน
    • ตอบถังผิด → ไม่ได้การ์ดคลุม จบตา (การ์ดยังอยู่ ให้ผู้ตัดสินอ่านถังที่ถูกให้ทุกคนฟัง ทีมไหนทายใบนี้ทีหลังแล้วตอบถูก จะได้ใบนี้)
ทีมที่คลุมครบทุกช่องของตัวเองก่อน ชนะ · ทีมไหนแตะ 🔥 แพ้ทันที

ตัวอย่าง

คำใบ้ "ครัว 3" → ทีมทาย เปลือกไข่ (ของทีม ✓) → บอกถัง "เขียว" ✓ ได้ใบ → ทาย กระดูกไก่ ✓ ถังเขียว ✓ ได้ใบ → ทาย ฟองน้ำล้างจาน (ของทีม ✓) → ตอบ "เหลือง" ✗ (จริงๆ คือน้ำเงิน) → จบตา

ตัวเลือก

  • ทั้งห้องเป็นทีมเดียว (ครูเป็นหัวหน้า): มี 10 ตา เก็บให้ได้ 8 ใบ ถ้าเจอกลางหรือตอบถังผิดเสียตา
  • เด็ก: ยกเลิกข้อห้ามคำเกี่ยวกับถัง และเอา 🔥 ออก
  • จับเวลา: ผู้ทายมี 2 นาทีต่อตา
